## Overview

REDCapLite is an independent open-source package designed to simplify REDCap API interactions for downstream applications and scripts.

## What It Provides

- Lightweight client patterns for common REDCap API operations
- Reusable request/response handling to reduce integration boilerplate
- A public repository for transparent usage examples and iteration
